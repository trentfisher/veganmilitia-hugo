I have been ranting and raving about lousy error messages for a very long time, you can see them all via the [errors]({{<relref "../tags/error">}}) tag.  I used to post details about how the error happend and how useless and/or misleading it was, how much productivity was lost debugging the problem, and the poor programming practices that caused it.  But it was sometimes hard to come up with some original snark, but I kept saving the error messages in case something came to mind.  But now I have almost 60 of them!  I don't have time to do this; not only do I need to work, but also sleep.  Instead I will just collect all my screenshots here, and I'll keep adding them.  That will be enough work.

Since I started doing this 16 years ago, this problem 
has only gotten exponentially worse, and using LLM slop as code will only accelerate this process.
Now, I know I am in a [glass house](https://en.wiktionary.org/wiki/people_who_live_in_glass_houses_shouldn%27t_throw_stones):
I have written lot of code and have made some of these mistakes myself and feel ashamed when exposed.  But then I go and fix it!  If you see yourself in this collection, do likewise!
